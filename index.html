📋 관리자 계정 가입

사람인 FIT 검사는 1기업 다계정을 지원합니다. 기업당 권한을 가진 1명의 Master(기업 계정)와 실무를 담당하는 다수의 Member(개인 계정)로 나뉘어 운영됩니다.

최초 1회에 한하여 신규 기업 계정 등록 비용 300,000원(VAT 별도)이 청구됩니다.

기업 관리자(Master) 가입

사람인 내부 관리자로부터 기업의 총괄 관리자인 Master로 초대받은 경우의 가입 절차입니다.

  1. 수신된 초대 메일 하단의 가입하기 버튼을 클릭하여 회원가입 페이지로 이동합니다. (링크는 발송 후 72시간 동안만 유효합니다.)
  2. 본인 인증: 휴대폰 또는 이메일 중 하나의 수단을 선택하여 본인 인증을 진행합니다.
  3. 정보 설정: 시스템에 등록된 기업 관리자 아이디(ID)는 고정되어 노출되며, 사용할 비밀번호(PW)를 새롭게 설정합니다.
  4. 이용 동의: 서비스 이용 동의 및 개인정보 위탁 동의 약관을 꼼꼼히 확인하고 필수 항목에 체크한 뒤 가입을 완료합니다.
🚨 Master 인증 시 주의사항

가입 본인 인증 시, 신청자의 '이름' 및 '이메일'과 가입을 진행하는 사용자의 인증 정보가 정확히 일치해야만 인증 및 가입이 가능합니다. (불일치 시 가입이 차단됩니다.)

실무 담당자(Member) 가입

기업의 Master 관리자로부터 시스템 운영을 함께할 Member로 초대받은 경우의 가입 절차입니다.

  1. Master가 발송한 초대 메일 하단의 가입하기 버튼을 클릭하여 회원가입 페이지로 이동합니다. (링크는 발송 후 72시간 동안만 유효합니다.)
  2. 정보 설정: 시스템 접속에 사용할 본인만의 아이디(ID)와 비밀번호(PW)를 직접 설정합니다. (※ 타 사용자와 동일한 ID는 중복 사용할 수 없습니다.)
  3. 본인 인증: 휴대폰 또는 이메일로 본인 인증을 진행합니다.
  4. 이용 동의: 서비스 이용 동의 및 개인정보 위탁 동의에 체크한 후 최종 가입을 완료합니다.
🚨 Member 인증 시 주의사항

가입 본인 인증 시, Master가 초대를 보낼 때 지정한 '이름' 및 '이메일'과 가입을 진행하는 사용자의 인증 정보가 정확히 일치해야만 인증 및 가입이 가능합니다. (불일치 시 가입이 차단됩니다.)

🔐 로그인 및 접속

관리자 페이지에 접속하여 부여받은 계정 ID와 PW를 입력합니다. 기업 데이터 보안을 위해 로그인은 2단계 본인 인증 절차를 거치게 됩니다.

접속 정보

  • 관리자 페이지 URL https://v2.testfit.co.kr/company
  • 시스템 문의 02-6377-2306, 2308

2단계 인증 가이드

  1. 아이디와 비밀번호를 입력한 후 로그인 버튼을 클릭합니다.
  2. '휴대폰 번호' 또는 '이메일' 중 인증 수단을 선택하고 인증번호 요청 버튼을 클릭합니다. (※ 단, 해외 거주자로 등록된 담당자의 경우 이메일 인증만 허용됩니다.)
  3. 발송된 인증번호 6자리를 확인하여 입력합니다.
  4. 인증번호를 넣고 인증 확인 버튼을 클릭하여 인증을 완료하면 메인 화면으로 이동합니다.
🚨 인증 실패 관련 보안 주의사항

2단계 인증 번호 입력을 5회 이상 실패할 경우, 30분간 계정 로그인이 강제로 차단됩니다. 30분이 모두 경과한 후 다시 시도해 주시기 바랍니다.

  • 오프라인 검사: 기본값 미사용으로 처리되며, 2차 인증 설정이 비활성화됩니다.

  • 문의처 노출 안내 문자 최하단에 노출될 문의처를 드롭다운 리스트에서 직접 선택합니다. 기업 대표 번호를 기본으로 제공하며, 시스템에 추가로 등록된 개별 담당자 연락처 중에서도 선택할 수 있습니다.
🚨 응시자 등록 후 설정 변경 제한

등록된 데이터의 정합성을 보장하기 위해 응시자가 1명이라도 등록된 이후에는 일부 설정의 변경이 엄격히 제한됩니다.

  • 2차 인증 사용 여부: [사용] ➔ [미사용] 변경은 가능하지만, [미사용] ➔ [사용]으로는 변경할 수 없습니다.
  • 2차 인증 수단 변경: 최초에 선택한 인증 수단(예: 휴대폰)을 도중에 다른 수단(예: 이메일)으로 변경할 수 없습니다.
  • 기본 정보 제한: 응시자 등록 완료 후에는 검사 시간, 검사 기간(시작일), 검사 언어, 검사 구분(온/오프라인) 수정이 차단됩니다.

일괄 등록 방법 (Excel)

대량 등록 데이터의 오류를 방지하기 위해 '전체 성공 또는 전체 실패(All-or-Nothing)' 무결성 방식이 적용됩니다. 파일 내 1건이라도 필수값이 누락되거나 형식이 다르면 전체 명단 업로드가 실패합니다.

  1. 왼쪽 엑셀 양식 다운로드 버튼을 클릭하여 제공되는 최신 템플릿 파일을 받습니다.
  2. 양식에 맞춰 정보를 기입합니다. (사전에 선택한 2차 인증 수단 연락처가 필수로 포함되어야 합니다.)
  3. 응시자 엑셀 등록 버튼을 클릭하여 작성한 파일을 업로드합니다.
📋 엑셀 등록 시 필수 유의사항
  • 반드시 다운로드 받은 양식을 이용해 예시와 동일한 형식으로 작성해 주시기 바랍니다.
  • 필수 항목: 수험번호, 이름
  • 특수문자 원천 차단: 개인정보 꼬임 방지를 위해 수험번호, 지원분야, 비고란에는 @ 와 . 기호 입력이 차단됩니다.
  • 안정적인 서버 전송을 위해 1회 등록 시 500명 이내로 파일을 나누어 등록하시길 권장합니다.

개별 등록 방법 (직접 입력)

  1. 응시자 행 추가+ 버튼을 클릭하여 정보를 한 명씩 화면에 바로 입력합니다.
  2. 모든 입력이 끝난 후 저장 후 다음 버튼을 클릭하여 명단을 확정합니다.
🚨 응시자 목록 관리 유의사항
  • 전체 노출 제한: 보안 정책에 따라 명단을 한 번 저장한 후 페이지에 재진입하시면, 정보 유출을 막기 위해 '현재 등록 인원: 00명'으로 요약 표시되며 세부 명단은 노출되지 않습니다. 세부 확인 및 수정은 응시자 관리 탭에서 별도로 진행하셔야 합니다.
  • 타이틀 항목 수정: 만약 타이틀 항목(수험번호, 이름, 비고1, 비고2 등) 수정을 희망하는 경우 해당 부분에 직접 타이핑 하여 내용 변경 후 타이틀 항목 수정 흰색 버튼을 누르면 적용 됩니다.
    (예시 : 수험번호 ➔ 응시번호, 비고1 ➔ 지역 ...)

🔒 접속 화면 2차 인증 유의사항

응시자가 제공받은 링크로 시험장에 접속할 때, 기업 관리자가 지정한 2차 인증 수단으로 본인 확인 절차가 열립니다.

  1. 재접속 시 재인증: 응시자가 브라우저를 닫고 다시 접속할 경우, 보안상 인증을 매번 새로 거쳐야 합니다.
  2. 응시자 임의 변경 불가: 응시자 본인이 직접 화면에서 자신의 인증 정보(휴대폰, 이메일)를 수정할 수 없습니다. 등록 시 업로드한 정보와 일치해야만 로그인이 허용됩니다.
⚠️ [중요] 2차 인증 5회 오류 시 접근 제한

응시자가 2차 인증 번호 입력을 5회 연속 실패할 경우, 30분간 검사 사이트 접속이 강제 차단됩니다.
이 조치는 관리자 권한으로도 초기화가 불가능하므로, 입력 정보가 정확한지 미리 확인하시는 것이 좋습니다.

5. 결과지 내 제외 항목 설정 (블라인드)

콘솔 바에 위치한 파란색 결과지 설정 버튼을 누르시면, 면접관에게 전달될 최종 PDF 다운로드 문서에서 특정 민감한 개인정보를 지워버릴(블라인드 마스킹) 수 있는 옵션 팝업이 노출됩니다. 공정한 블라인드 채용이나 면접관의 선입견 방지를 위해 매우 유용하게 쓰이는 기능입니다.

* 응시자 명단 업로드 시 '수험번호'와 '면접번호' 두 열을 모두 채워 넣으셨다면, 문서상에는 '면접번호'가 수험번호를 덮어쓰고 최우선으로 노출되는 로직이 적용되어 있습니다.

만약 면접번호 대신 본래 지원자의 수험번호를 명확히 표기하고 싶으시다면, 이 블라인드 옵션 팝업 창을 열어 '면접번호' 항목을 체크하여 가림 처리해 주시면 수험번호가 정상적으로 대체 표기됩니다.

6. 부적격 판별 기준 설정

각 기업과 직무마다 요구하는 최소 합격 허들 수준이 다를 수 있습니다. 파란색 판별 기준 설정 버튼을 클릭하여 지원자의 부적격 탈락 컷라인 점수 기준을 우리 기업에 맞게 수동으로 섬세하게 커스텀 조정할 수 있습니다.

💡 기본값 및 커스텀 조정 예시

  • 시스템 자동 기본값 기본적으로 종합점수/인성/직무 점수가 40점 미만이거나, 신뢰도 80점 미만, 혹은 부적응성 검사 내 1개 이상의 항목이 80점 이상 위험 수준일 시 결과지에 자동으로 '부적격' 도장이 찍히게 설정되어 있습니다.
  • 조정 예시 우리 회사는 인성을 특히 중시하기 때문에 인성검사의 부적격 기준을 60점 이상으로 상향 세팅하면, 이후 60점 미만을 득점한 지원자는 모두 시스템 필터에서 일괄 '부적격'으로 판정됩니다.
🚨 기준값 변경 시 주의사항

이 기준값 조정은 가급적 지원자가 실제 검사에 돌입하기 전(Step 1 등록 시점)에 세팅을 마치시는 것이 가장 안전합니다. 응시 데이터가 이미 쌓인 도중에 기준을 갑자기 수정하게 되면, 결과 산출 로직에 에러가 발생하여 지원자 간 형평성이 엇갈릴 우려가 있습니다. 부득이하게 변경이 필요하신 경우 시스템 관리자 문의처(02-6377-2306)로 지원을 요청하시기 바랍니다.

7. 개인 결과표 확인 (웹 화면)

응시자 리스트 항목의 가장 우측에 위치한 보기 텍스트 버튼을 클릭하시면, 무거운 엑셀이나 PDF 파일을 로컬로 다운로드할 필요 없이 웹 브라우저 팝업 내에서 즉각적이고 가볍게 해당 지원자의 개별 상세 리포트 전체를 열람할 수 있습니다.

⚠️ 정보 보호 정책 (데이터 자동 파기 알림)
데이터 파기 임박 시각화 및 시스템 편집 제어

신규 검사 등록 시 설정해 두었던 '보관 기간' 정책에 따라 파기 로직이 엄격하게 가동됩니다.

  • 붉은색 경고 알림: 검사 결과 데이터의 완전 파기 예정일이 30일 이내로 다가온 응시자 행은 리스트 상에서 눈에 띄게 붉은색 배경으로 물들어 표시됩니다. 관리자는 해당 행을 클릭하여 정확한 소멸 기한을 점검하고 백업 여부를 결정할 수 있습니다.
  • 편집 기능 전면 블락: 설정한 최소 보관 기간(연락처 보관 기간 등)이 만료되어 데이터 비식별화 및 파기 프로세스가 이미 가동된 지원자 행에 대해서는 데이터 수정, 응시자 삭제 기능 등의 물리적 개입 버튼 접근이 원천 차단됩니다.

❓ FAQ

관리자 시스템 운영 중 자주 발생하는 궁금증이나 오류 사항에 대한 해결책입니다. 문의 전 우선적으로 점검해 주시기 바랍니다.

Q. 관리자 계정 아이디와 비밀번호를 잊어버렸습니다.
기업 보안상의 이유로 시스템 화면 내에 아이디/비밀번호 간편 찾기 기능은 제공되지 않습니다. 시스템 공식 문의처(02-6377-2306, 2308)로 연락을 취해 주시면, 철저한 권한 확인 절차를 거친 후 안전하게 초기화 및 안내를 도와드립니다.
Q. 지원자가 2차 인증을 연달아 실패하여 사이트 접속이 막혔다고 합니다. 어떻게 풀어주나요?
대리 응시 방지 정책상 관리자가 임의로 풀어줄 수 없습니다. 2차 인증 번호 입력을 5회 이상 연속으로 틀리면 자동으로 30분간 시험장 접속이 강제 차단됩니다. 30분이 지난 후, 지원자가 본인의 휴대폰 등 정확한 정보로 다시 인증을 시도하도록 안내해 주시기 바랍니다.
Q. 명단에서 지원자들의 이름과 연락처가 *** 로 모자이크 처리되어 있어 식별이 어렵습니다.
개인정보 노출을 최소화하기 위해 기본적으로 적용되는 '데이터 마스킹 보안 모드' 때문입니다. 지원자의 전체 정보를 투명하게 열람하시려면, 화면 우측 상단 톱니바퀴나 계정 메뉴를 열어 상세 보기 모드로 일시 전환해 주시면 됩니다.
Q. 엑셀을 일괄 업로드하는데 자꾸 실패 알림이 뜹니다. 제대로 된 사람만 먼저 부분 등록은 안 되나요?
안정적인 데이터 관리를 위해 현재 시스템은 '전체 성공 또는 전체 실패(All-or-Nothing)' 방식을 채택하고 있습니다. 500명의 파일 중 단 한 명의 정보라도 양식(점, 특수문자 삽입 등)에 어긋나면 500명 전원의 업로드가 거부됩니다. 다소 번거로우시더라도 에러가 발생한 셀을 꼼꼼히 보완하신 뒤 온전한 파일을 통째로 다시 업로드해 주십시오.
Q. 지원자 연락처를 잘못 입력했습니다. 지금 제가 수정해도 되나요?
해당 지원자가 아직 검사 링크를 클릭해 접속하지 않은 '대기' 상태라면, 응시자 관리 메뉴에서 관리자가 수동으로 즉시 정보를 변경할 수 있습니다. 단, 이미 지원자가 검사장에 진입하여 '응시 중'이 되었거나, '응시 완료'한 경우, 혹은 파기 기한 도래로 데이터가 시스템에서 소거된 상태에서는 어떠한 수정 조작도 불가능합니다.
Q. 개인정보 보관 기간을 우리 기업 일정에 맞춰 뒤늦게 더 늘릴 수 있나요?
불가능합니다. 응시자가 단 1명라도 등록을 마친 프로젝트는, 최초 세팅한 '데이터 보관 기간' 사후에 늘리거나 줄일 수 없도록 자물쇠가 걸립니다. 정해진 기간이 만료되면 데이터가 영구 삭제되므로, 이력 보관이 필요하시다면 반드시 파기 기한 도래 이전에 엑셀이나 PDF 형태로 자체 백업을 마련해 두셔야 합니다.
Q. PDF 다운로드 버튼을 눌렀는데 화면에 아무런 반응도 없고 파일도 안 받아집니다.
열어두신 브라우저(크롬, 엣지 등)의 팝업(새 창) 차단 기능이 무음으로 활성화되어 있는지 확인해 주십시오. 주소창 우측 상단의 경고 아이콘을 클릭해 해당 사이트의 팝업 권한을 '항상 허용'으로 푸신 뒤 시도해 주시기 바랍니다.
Q. 부적격 판별 기준 점수 컷라인은 언제 설정하거나 수정해야 안전한가요?
결과표 점수 도출 및 부적격 판별 로직의 오류를 완전히 방지하기 위해 반드시 지원자가 검사에 응시하기 전에 기준 세팅을 모두 완료해 주셔야 합니다. 검사가 이미 진행된 이후 부득이하게 커트라인 수정이 필요하신 경우에는, 번거로우시더라도 시스템 관리자 문의처로 즉각적인 기술 지원을 요청해 주시기 바랍니다.
Q. 회사 내부에서 자체적으로 시스템 테스트를 진행할 때 유의해야 할 사항이 있나요?
실제 채용 지원자 데이터 통계와 섞이지 않게 하는 것이 가장 중요합니다. 테스트용으로 검사 방을 여실 때는 검사 타이틀이나 가상 응시자의 이름에 'TEST' 또는 '테스트'라는 키워드를 꼭 명확히 포함하여 기재해 주시길 권장해 드립니다.
Q. 며칠째 '응시 중' 상태로 멈춰 있는 지원자가 있습니다. 이 사람을 강제로 채점 완료시키거나 아예 삭제하고 싶은데요.
일시적 오류 시 횟수를 늘려주는 등의 조치는 관리자 권한으로 버튼 한 번이면 되지만, 도중 하차한 인원을 강제 채점하거나 완전히 기록을 삭제하는 고급 쿼리 작업은 관리자 화면에서 직접 할 수 없습니다. 이런 특수한 상황은 시스템 문의처(02-6377-2306)로 전화를 주시면 내부에서 상황 파악하고 신속하게 조율해 드립니다.
Q. 비용 결제를 위한 대금 청구와 세금계산서 발행은 어떻게 진행되나요?
시스템이 기업의 월별 총 이용(채점) 내역을 안전하게 모아두었다가, 다음 달 첫 영업일에 정산 상세 내역서를 담당자 메일로 발송해 드리고 있습니다. 수신하신 내역에 이상이 없음을 확인 회신해 주시면 세금계산서를 즉시 발행해 드리며, 이후 안내된 지정 계좌로 이용 대금을 입금해 주시면 모든 절차가 완료됩니다. (월 결제가 아닌 특정 건별 개별 정산이 필요하신 경우에는 별도 문의를 부탁드립니다.)
Q. 검사 비용(과금)이 발생하는 정확한 기준점이 궁금합니다.
검사를 끝까지 완료하여 '최종 결과(성적표)가 정상적으로 도출(생성)된 인원 수'만을 카운트하여 비용을 청구합니다. 등록만 해두고 시험장에 오지 않은 인원(대기 중)이나, 시험을 치다 중간에 나가버려 결과지가 나오지 못한 미완전 인원에 대해서는 검사 비용을 한 푼도 받지 않으니 안심하십시오.
